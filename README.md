# 🐾 ウチのペットLINEスタンプメーカー（個人用）

ペットの写真1〜3枚と名前を入れると、AI（Claude）が特徴を読み取り、
10種類の顔テンプレートから1つを選んで、シンプルなキャラクターとLINEスタンプ8種類を作ります。

## 使い方

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
# → http://localhost:3000 をブラウザで開く
```

1. **写真と名前**：写真を1〜3枚えらんで名前を入れ、「キャラクターを生成」
2. **キャラクターシート**：前・横・後ろ、喜怒哀楽、ポーズ4種が並んだシートを確認
   - イメージと違えば「顔が違う方が良い」「もう少し特徴を捉えて」などをえらぶか、自由に入力して再生成
   - 顔テンプレートはプルダウンから手動でも変えられます（AI呼び出しなし）
3. **スタンプ**：シートがOKなら8種類（おはよう／おやすみ／ありがとう／OK！／ごめんね／おつかれさま／よろしくね／だいすき）を生成
   - 文字は書き換え可能
   - ZIPで `01〜08.png`（370×320）、`main.png`（240×240）、`tab.png`（96×74）、キャラクターシートをまとめて保存

APIキーがなくても、画面の「APIなしでお試し」でランダムなキャラを作って動作を確認できます。

## しくみ

- `server.js`：静的ファイル配信と `/api/analyze`。写真を Claude（`claude-opus-5-5`）に渡し、
  構造化出力で「テンプレート・色・模様・目/鼻・しっぽ・小物・特徴」のJSONを返します。
  再生成時は前回のJSONと修正指示を一緒に送ります。APIキーはサーバー側だけで使い、ブラウザには出しません。
  AIが応答を断った場合に別モデルで自動再試行する server-side fallback を有効にしています。
- `public/render.js`：JSONからSVGでキャラを描画（10テンプレート × 前/横/後ろ × 表情 × ポーズ）。
- `public/compose.js`：キャラクターシートとスタンプをcanvasで組み立て（透過PNG）。
- `public/app.js`：画面の流れ。

環境変数：`PORT`（既定 3000）、`CLAUDE_MODEL`（既定 `claude-opus-5-5`）。
